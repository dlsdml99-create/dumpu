# 덤푸

한 달 할 일을 우다다 적고, 주차·요일 버튼으로 위클리·데일리에 정리하는 플래너 앱.

- **다운로드 페이지 (설명서 포함)**: https://dlsdml99-create.github.io/dumpu/
- **안드로이드 앱 바로 받기**: https://github.com/dlsdml99-create/dumpu/releases/latest/download/dumpu.apk
- **아이폰·웹에서 쓰기**: https://dlsdml99-create.github.io/dumpu/app/

## 기능
- 먼슬리: 위에 달력·아래에 한 달 할 일, 우다다 적고 주 버튼이나 📅 날짜로 정리
- 달력에 공휴일(설날·추석·대체공휴일, 2026~2028)과 생일·기념일 표시
- 위클리: 요일 버튼으로 데일리로 내리기, 체크하면 완료 날짜 기록
- 데일리: 타임라인, "3시 병원"처럼 쓰면 시간 자동 인식, 날짜·시간 고치기
- 밀린 일 한 번에 옮기기, 반복 할 일(월·수·금처럼 여러 요일, 매달), 카테고리 8개(이름·색)
- 할 일 타이머: ▶ 누르고 ■ 누르면 한 시간이 10분 칸에 자동 기록
- 습관 탭, 오늘 기분 이모지와 한 줄 일기, 이번 달 돌아보기 이미지
- 할 일 시간 알림(10분 전 등), 홈 화면 위젯, 아침 알림 (안드로이드)

## 안전
- 할 일은 기기 안에만 저장. 계정·서버·광고·사용 기록 전송 없음.
- 인터넷은 새 버전 확인(GitHub 공개 릴리스 정보 읽기)에만 사용.
- 권한: 인터넷, 알림(켤 때만 요청), 부팅 후 알림 다시 잡기. 카메라·위치·연락처 없음.

## 만드는 법 (개발용)
- 앱 화면: `web/` (버전은 `web/index.html`의 `app-version` 한 곳)
- 안드로이드: `app/` (WebView + 위젯 + 알림)
- `main`에 올리면 GitHub Actions가 APK를 만들어 릴리스와 다운로드 페이지에 올림
- 서명 키는 저장소에 없고, Secrets의 `SIGNING_KEY`(`비밀번호:base64`)로만 씀
